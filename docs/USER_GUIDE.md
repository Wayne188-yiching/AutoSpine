# AutoSpine 使用說明

## 1. 準備檔案

- 先依[安裝指南](INSTALL.html)裝好外掛。電腦需有 Node.js 22.12 以上、Spine 4.0.64 和 ffmpeg。
- 準備角色的 `.spine` 檔及圖片資料夾，部件需已拆好並擺好位置。
- 有參考影片時一起提供（美術輸出的影片、其他專案的動畫或生成影片皆可）。背景需為單一顏色，影片從動畫第 0 幀開始；不是的話，說明從第幾秒開始。
- 要比對人工動畫時，另外提供人工版 `.spine` 檔。

## 2. 說明需求

在 Claude Code、Cowork 或 Codex 輸入：

```text
用 autospine 把 D:\素材\角色\角色.spine 的 idle 做成 2 秒循環呼吸，手扶著額頭不動，輸出到 D:\輸出\角色
```

請寫清楚：

- **動畫**：名稱、長度、循環或單次。
- **姿勢**：開頭與結尾的樣子；有多組姿勢時，指定使用哪一組。
- **手和道具**：拿著、扶著或固定在哪裡。
- **細節**：擺動幅度、是否眨眼、眼神往哪裡看。

單次動作建議附幾張關鍵姿勢圖，標明第幾幀，包含開頭和結尾。只有動畫名稱時，動作可能與預期不同。

有參考影片時，加上：

```text
動作照 D:\素材\角色\參考_idle.mp4，做完和影片比對驗收
```

想讓動作直接跟著影片做（不只是比對），改說：

```text
動作直接照 D:\素材\角色\參考_idle.mp4 擬合，做完和影片比對驗收
```

AutoSpine 會把影片每一幀對到角色的骨架上，每個部件從前一幀的位置接著找，前後各追一次；兩次結果不一致的幀不採用，改由前後幀補上，並在對話中列出。影片裡比上一節骨頭晚動或早動的部件（例如頭比身體晚幾幀），會保留這個錯幀，交付說明會寫出哪根骨比哪根晚幾幀。循環動畫會找出影片重複的週期，疊成一個循環；再整理成稀疏的關鍵幀，最多跑 3 輪「建置 → 比對 → 修正」，交付比對結果最好的一輪。這樣做出的動畫標為「參考影片擬合」，不算盲測。表情、網格變形、縮放，以及影片裡畫法不同的部件不會擬合，會在對話中列出。生成影片若把角色重畫（例如側面畫成正面），請只用來比對。

需要人工版比對時，加上：

```text
和 D:\素材\角色\人工版.spine 比對
```

## 3. 查看結果

輸出在指定資料夾。未指定時，放在原 `.spine` 旁的 `AutoSpine\<動畫>` 資料夾。

| 檔案                      | 內容                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| `<名稱>.spine`            | 可直接開啟的 Spine 專案                                                                          |
| `<名稱>.mp4`              | 依序播放網格、骨架、完整動畫；有人工版時左為人工、右為 AutoSpine                                 |
| `<名稱>-vs-reference.mp4` | 有參考影片時才有：左為參考影片、中為 AutoSpine、右為差異（越亮差越多）。多段動畫時檔名含動畫名稱 |
| `images/`                 | 專案用到的圖（原圖資料夾裡的其他檔案不會複製），交付時需一起保留                                 |
| `_work/`                  | 原始資料副本、方案、建置與比對紀錄，以及交付紀錄 `delivery.json`（判斷交付後是否在 Spine 改過）  |

看影片確認擺位、接縫、變形和動作。驗收項目全部 PASS，也需要目視確認。沒有安裝 Spine 時，交付檔改為 JSON，用 Spine 的 Import Data 匯入。

有參考影片時，對話中會列出和影片比對的結果：

| 項目 | 檢查什麼                                     |
| ---- | -------------------------------------------- |
| V1   | 整體輪廓和參考影片重疊多少                   |
| V2   | 每個部件的位置和參考影片差多少（以身高計算） |
| V3   | 整體動作的時間（快或慢幾幀）與幅度           |
| V4   | 循環動畫的頭尾接得上                         |

只比對時，沒通過只會回報哪裡不同、可以怎麼改，由你決定要不要修改，不會自動重做；選擇擬合時才會自動修正，最多 3 輪。顏色不在比對範圍內；影片裡的特效（煙塵等）或生成影片改畫的部件，也會讓結果不通過。

## 4. 修改

直接指出要改的地方，例如：

```text
頭部擺動小一點
拐杖要跟著手動
臉不要一直滑動
走路那段頭部以下左右翻轉
```

修改後會重新建置並提供影片。若已在 Spine 手動改過交付檔，重做前請先說明；手動修改不會回寫到方案。

## 5. 精簡 Key

任何 Spine 4.0 檔（人工做的或 AutoSpine 做的）都可以在不明顯改變動作的前提下減少 Key，方便美術繼續用姿勢編修：

```text
用 autospine 精簡 D:\素材\角色\角色.spine 的 Key，兩種模式都做，輸出到 D:\輸出\角色-精簡
```

- **保真精簡**：只留下原本的 Key 中必要的那些，重新擬合貝茲曲線；誤差上限預設為骨架高度的 0.1%（RMS 0.03%）。
- **可編修姿勢**：主要骨骼對齊到共同的姿勢格（預備、壓縮、起跳、最高點、接地、恢復，或循環的高低點、支撐、交換），新 Key 落在整數幀；頭髮、尾巴、耳朵等跟隨部件保留自己的轉折與延遲。誤差上限預設為骨架高度的 0.3%（RMS 0.1%）。

兩種模式的上限分開設定，不會為了刪更多 Key 自動放寬。每個結果都用官方 Runtime 播放、和原檔逐點比對世界座標頂點（含骨骼階層、權重、IK／Transform／Path 約束與網格變形）；誤差超過的地方只在該部件、該時間補 Key，補不到就把那幾條通道（必要時整段動畫）恢復成原本的 Key，並在報告寫明。換圖、繪製順序、事件、有跳變的 stepped Key 與指定鎖定的 Key 不會被刪。原檔不會被修改（前後比對 SHA-256）。

輸出資料夾：

| 檔案                           | 內容                                                                                                      |
| ------------------------------ | --------------------------------------------------------------------------------------------------------- |
| `fidelity/`、`posable/`        | 各模式的 `.spine`（用 Spine 匯入）、JSON、`roundtrip/`（再匯出的 JSON）、`key-report.json`                |
| `key-reduction-report.html`    | 每段動畫、每條通道的前後 Key 數、誤差、最差時間與部件、姿勢節點、跟隨延遲、接地滑動、循環接縫、Key 分佈圖 |
| `preview.mp4`                  | 原始｜保真精簡｜可編修姿勢，依序播放網格、骨架、動態                                                      |
| `source/`、`roundtrip-source/` | 原檔匯出的 JSON，與原檔自己經 Spine 匯入匯出的對照                                                        |

手動執行（`--mode=fidelity` 或 `posable` 只做一種；`--fidelity-max=1`、`--posable-max=3` 指定上限 px；`--lock=idle::bone:hip/rotate@0.5` 鎖定 Key；`--animations=idle,in` 限定範圍）：

```bash
node packages/cli/dist/index.js reduce-keys "D:\素材\角色\角色.spine" "D:\輸出\角色-精簡"
```

精簡後若在 Spine 改過，又想再精簡一次，加 `--baseline=<上次 source 資料夾裡的 JSON>`：沒改過的動畫會從原檔重算（結果相同，不會累積誤差），改過的動畫以目前內容為準。用方案建置時，可在方案 `motion.keyReduction` 指定模式，之後每次重建都會自動精簡。

## 檔案保留與限制

- 原檔使用副本處理，不會直接修改。
- 新版取代交付檔前，舊版會收進 `_work/`；已手動修改的交付檔需先確認。
- 確定不再重做後可刪除 `_work/`。交付給別人時，保留 `.spine` 和 `images/`。
- 目前不會依參考圖片自動產生表情、吐舌頭等網格變形，也不會自動驗收顏色。

手動指令與方案格式見 [CHARACTER_PLAN.md](CHARACTER_PLAN.md)。
