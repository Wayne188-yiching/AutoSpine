# AutoSpine 使用說明

## 1. 準備檔案

- 先依[安裝指南](INSTALL.html)裝好外掛。電腦需有 Node.js 22.12 以上、Spine 4.0.64 和 ffmpeg。
- 準備角色的 `.spine` 檔及圖片資料夾，部件需已拆好並擺好位置。
- 有參考影片時一起提供（美術輸出的影片、其他專案的動畫或生成影片皆可）。背景需為單一顏色，影片從動畫第 0 幀開始；不是的話，說明從第幾秒開始。
- 要比對人工動畫時，另外提供人工版 `.spine` 檔。

## 2. 說明需求

在 Claude Code、Cowork 或 Codex 輸入：

```text
用 autospine 把 D:\素材\角色\角色.spine 的 idle 做成 2 秒循環呼吸，手扶著額頭不動，輸出到 D:\輸出\角色
```

請寫清楚：

- **動畫**：名稱、長度、循環或單次。
- **姿勢**：開頭與結尾的樣子；有多組姿勢時，指定使用哪一組。
- **手和道具**：拿著、扶著或固定在哪裡。
- **細節**：擺動幅度、是否眨眼、眼神往哪裡看。

單次動作建議附幾張關鍵姿勢圖，標明第幾幀，包含開頭和結尾。只有動畫名稱時，動作可能與預期不同。

有參考影片時，加上：

```text
動作照 D:\素材\角色\參考_idle.mp4，做完和影片比對驗收
```

需要人工版比對時，加上：

```text
和 D:\素材\角色\人工版.spine 比對
```

## 3. 查看結果

輸出在指定資料夾。未指定時，放在原 `.spine` 旁的 `AutoSpine\<動畫>` 資料夾。

| 檔案                      | 內容                                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| `<名稱>.spine`            | 可直接開啟的 Spine 專案                                                                          |
| `<名稱>.mp4`              | 依序播放網格、骨架、完整動畫；有人工版時左為人工、右為 AutoSpine                                 |
| `<名稱>-vs-reference.mp4` | 有參考影片時才有：左為參考影片、中為 AutoSpine、右為差異（越亮差越多）。多段動畫時檔名含動畫名稱 |
| `images/`                 | 專案用圖，交付時需一起保留                                                                       |
| `_work/`                  | 原始資料副本、方案、建置與比對紀錄                                                               |

看影片確認擺位、接縫、變形和動作。驗收項目全部 PASS，也需要目視確認。沒有安裝 Spine 時，交付檔改為 JSON，用 Spine 的 Import Data 匯入。

有參考影片時，對話中會列出和影片比對的結果：

| 項目 | 檢查什麼                                     |
| ---- | -------------------------------------------- |
| V1   | 整體輪廓和參考影片重疊多少                   |
| V2   | 每個部件的位置和參考影片差多少（以身高計算） |
| V3   | 整體動作的時間（快或慢幾幀）與幅度           |
| V4   | 循環動畫的頭尾接得上                         |

沒通過時只會回報哪裡不同、可以怎麼改，由你決定要不要修改，不會自動重做。顏色不在比對範圍內；影片裡的特效（煙塵等）或生成影片改畫的部件，也會讓結果不通過。

## 4. 修改

直接指出要改的地方，例如：

```text
頭部擺動小一點
拐杖要跟著手動
臉不要一直滑動
走路那段頭部以下左右翻轉
```

修改後會重新建置並提供影片。若已在 Spine 手動改過交付檔，重做前請先說明；手動修改不會回寫到方案。

## 檔案保留與限制

- 原檔使用副本處理，不會直接修改。
- 新版取代交付檔前，舊版會收進 `_work/`；已手動修改的交付檔需先確認。
- 確定不再重做後可刪除 `_work/`。交付給別人時，保留 `.spine` 和 `images/`。
- 目前不會依參考圖片自動產生表情、吐舌頭等網格變形，也不會自動驗收顏色。

手動指令與方案格式見 [CHARACTER_PLAN.md](CHARACTER_PLAN.md)。
