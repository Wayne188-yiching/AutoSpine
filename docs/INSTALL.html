AutoSpine 安裝指南

安裝 AutoSpine 外掛後，可在 Claude 或 Codex 製作 Spine 骨架與動畫。

1

先準備

安裝 Node.js 22.12 以上：

winget install OpenJS.NodeJS.LTS

要匯出 Spine 檔、產生檢查影片的話，電腦也要有 Spine 4.0.64 和 ffmpeg；要交付成 3.8、4.1、4.2 專案時，Spine 啟動器會自動下載該版。

2

安裝外掛

Claude（桌面 App、Cowork、Claude Code 共用）

  1. 左側選單點 自訂，選 外掛程式。
  2. 按右上角 ＋ 新增 → 新增市集。
  3. 在「網址」貼上下面這行，按 同步。 
    Wayne188-yiching/AutoSpine
  4. 到 探索 找到 AutoSpine，點開後按 新增。

私有儲存庫需使用有存取權限的 GitHub 帳號登入。

Codex：在終端機執行下面這行，再到 Plugins 安裝 AutoSpine。

codex plugin marketplace add Wayne188-yiching/AutoSpine
3

開始用

先確認裝好了：

用 autospine 跑內建範例

之後直接說要做什麼：

用 autospine 把 D:\素材\角色\角色.spine 的 idle 做成 2 秒呼吸

輸出包含 Spine 專案與檢查影片，工作檔收在 _work 資料夾。看完影片後，直接說明要修改的地方。
