先準備

每台電腦一次。裝完 Node.js 或 ffmpeg 後，要把 Claude 或 Codex 整個關掉再開，才抓得到。

Node.js 22.12 以上必要

AutoSpine 引擎靠它執行。外掛已經內含整個引擎，不用下載程式碼，也不用 npm install。 

winget install OpenJS.NodeJS.LTS

或從 nodejs.org 下載 LTS 版。檢查：node --version 要顯示 v22.12.0 以上。

GitHub 權限必要

外掛放在私人 repo Wayne188-yiching/AutoSpine。請 Wayne 用你的 GitHub 帳號邀請你，並到信箱或 GitHub 通知接受邀請。

Spine 4.0.64建議

用來把 .spine 匯出成 JSON、把結果存回 .spine。沒有命令列可用時，自己在 Spine 匯出 JSON（含 nonessential data）交給它也可以。

ffmpeg建議

產生檢查影片 review.mp4（依序播放佈線、骨架、完整動態）。

winget install Gyan.FFmpeg

檢查：ffmpeg -version。

安裝外掛

用哪個就裝哪個。Claude 裝一次會綁在帳號上，Claude Code 會自動同步，不用再裝。

Claude 桌面 App、Cowork

也會同步到 Claude Code
  1. 打開 Claude 桌面 App（或 claude.ai），進入 Customize（自訂）→ Plugins（外掛）。
  2. 選 Add → Add marketplace，輸入： 
    Wayne188-yiching/AutoSpine
  3. 第一次會要求連結 GitHub，並允許 Claude GitHub App 存取這個 repo，照畫面完成。
  4. 在清單找到 AutoSpine，按 Add。
  5. Claude Code 下次啟動會自動同步；已經開著的話，輸入 /reload-plugins。

外掛裡的 AutoSpine 連接器標示 Runs in each session，表示它在你自己的電腦上執行。Claude Code 和跑在你電腦上的 Cowork 會自動接上。接不上的環境，AI 會直接執行外掛內建的引擎，結果相同。

網頁版聊天碰不到你電腦上的檔案，請在 Cowork 或 Claude Code 使用。

只用 Claude Code

終端機、IDE 擴充、桌面 App 的 Code 分頁

已經在 Claude App 裝過就不用做這步。沒有的話，在 Claude Code 輸入（Claude Code 2.1.275 以上）： 

/plugin install autospine --marketplace Wayne188-yiching/AutoSpine

這是私人 repo，你的 git 要能讀到它。先在終端機確認：

git ls-remote https://github.com/Wayne188-yiching/AutoSpine

有列出內容就可以；要求登入時，用 GitHub 帳號登入（Windows 版 Git 會跳出登入視窗，或先執行 gh auth login）。

Codex

CLI 與 Codex App

方法一：外掛。在終端機加入來源，再到 Codex App 的 Plugins 目錄選 AutoSpine 安裝（不同版本的選單名稱可能略有不同）。 

codex plugin marketplace add Wayne188-yiching/AutoSpine

方法二：只裝 skill。外掛功能不能用、或想最快裝好時，用 PowerShell 把 skill 複製到 Codex 的 skills 資料夾。skill 已經內含引擎，功能相同，只是不走 MCP。 

git clone --depth 1 https://github.com/Wayne188-yiching/AutoSpine "$env:TEMP\AutoSpine"
New-Item -ItemType Directory -Force "$env:USERPROFILE\.agents\skills" | Out-Null
Copy-Item -Recurse -Force "$env:TEMP\AutoSpine\plugin\skills\autospine" "$env:USERPROFILE\.agents\skills\"
Remove-Item -Recurse -Force "$env:TEMP\AutoSpine"

裝好後在 Codex 輸入 /skills，清單裡要看得到 autospine。

第一次使用

  1. 先確認安裝正常。在任何對話說： 
    用 autospine 跑內建範例，確認安裝正常
    它會建出一個 20 根骨的範例角色並回報結果。這個範例是程式畫的測試角色，不含任何美術資產。
  2. 正式做角色，直接給原檔路徑和需求： 
    用 autospine 把 D:\素材\角色\角色.spine 的 idle 做成 2 秒呼吸，手扶著額頭不動，輸出到 D:\輸出\角色
    它會先把檔案複製到工作資料夾 C:\Users\你的帳號\AutoSpine\ 再處理，原檔不會被改。
  3. 看完 review.mp4，直接說哪裡要改，例如「拐杖要跟著手動」「樹冠擺動再大一點」。它會改方案、重建，再給新影片。最後的細節在 Spine 裡手修。

單次動畫（進場、退場、勝利）最好附幾張關鍵姿勢圖並標幀號，例如「第 0、8、14、44、60 幀」。只給名稱時動作是用猜的。完整寫法見 使用說明。

更新

Wayne 推出新版後，各環境這樣拿到：

  • Claude App／Cowork：會從 GitHub 自動更新。要馬上更新，到 Customize → Plugins，在 AutoSpine 這個 marketplace 按 Check for updates。
  • Claude Code 指令安裝的：/plugin marketplace update autospine
  • Codex 方法一：codex plugin marketplace upgrade
  • Codex 方法二：重新執行上面那段 PowerShell。

疑難排解

「node 不是內部或外部命令」或 node not found
安裝 Node.js 22.12 以上，然後把 Claude 或 Codex 完全關掉再開。
新增 marketplace 時說沒有權限
確認已接受 repo 邀請；在 Claude 連結 GitHub 並允許 Claude GitHub App 存取 AutoSpine。
AI 說沒有 autospine 工具
沒有 MCP 也能做，它會改用內建引擎。若連 autospine 技能都沒有，確認外掛是開啟狀態；Claude Code 輸入 /reload-plugins。
錯誤碼 MCP_WORKSPACE_POLICY
檔案不在工作資料夾內。請它先把檔案複製到 使用者資料夾\AutoSpine 再做。
錯誤碼 CLI_OUTPUT_EXISTS 或 MCP_OUTPUT_EXISTS
輸出資料夾已經存在。它不會覆蓋舊結果，請它換一個新資料夾名稱。
沒有產生檢查影片
安裝 ffmpeg，重開 App 後再請它重做影片。
想換工作資料夾
設定系統環境變數 AUTOSPINE_WORKSPACE，例如 D:\AutoSpine，重開 App。

給維護者

改了引擎或文件之後，同事要拿到新版：

  1. 在 AutoSpine repo 重新產生外掛內容（引擎單檔、參考文件、範例角色）： 
    npm run build:plugin
  2. 把三個檔案的 version 一起加一：plugin/.claude-plugin/plugin.json、plugin/.codex-plugin/plugin.json、.claude-plugin/marketplace.json。
  3. 跑 npm test（會檢查外掛跟程式碼是否同步），commit 後推上 main。

邀請同事：GitHub 上的 AutoSpine repo → Settings → Collaborators → Add people。

AutoSpine 外掛 0.1.0。外掛只在執行對話的電腦上運作，不會把檔案傳到其他地方。
