- 身份使用 project／skin／slot／attachment，加上 `.spine`、JSON、PNG 雜湊；失敗附件也保留，不只挑通過的案例。

## 本輪審核實作

- 逐附件絕對點數差 ≤5，取代歷史 ±20%；旧鬍鬚／房屋兩筆點數不得再單獨解鎖 Gate。
- 外框／內部點分別作一對一匹配，避免同一個生成點重複充當多個人工點。
- 位置平均 5%、P95 10%、最大 15% 是暫定研究篩選值，以 PNG 對角線正規化；未配對点記 100%。這代表任何未配對點都使目前位置門檻失敗，不應把它當成使用者已確認的 ±5 點容許策略。
- 比對人工實線在生成三角化中的連通保留；這不等於生成器已有可編輯實線語意，MeshSpec 本輪沒有增加該欄位。
- 目前每個可生成附件只重跑 2 次；正式全語料 100 次驗收未完成。初始量測只提供數量／外框數 profile；最新一輪另依使用者決定提供人工外框限定的有效 alpha 與實測留白預算，不直接提供人工 XY 或內部連線，不把人工頂點複製成生成結果。
- 新增讀取、線型、匹配、完整語料與舊審核繞過的回歸測試；Windows 換行格式採 auto，避免無關全庫改寫。

## 已由使用者確認的規則衝突

Yuuna `Bow02`：人工 6 點。原始 alpha 有 514 個前景像素，人工外框在 PNG 範圍內另外包覆 151 個透明像素，即 29.3774%；漏覆 1 個前景像素，即 0.1946%。採像素中心射線判斷，alpha >0 為前景。此圖前處理沒有丟棄、補洞或修角，因此原始與處理後 mask 相同。

使用者已明確決定：以同附件人工留白為準，同時維持頂點數 ±5 與漏覆檢查。新 `artist-padding-5-v3` 規則以人工多覆／原始前景為上限，生成漏覆仍 ≤2%；獨立審核從原始 PNG 重算，不能只相信報告中的 PASSED。生成器只接收測量後的數值預算，不讀取人工 XY。無參考路徑不變；前處理丟棄／補洞預算不變，超限案例保留失敗。此變更不等於完成位置、人工邊流或動畫驗收。

## 可重跑工作流

### 人工使用區域補充決定

`pig/2_string` 的實際 PNG 含細繩和其他圖像；人工 7 點網格只選細繩。整張 PNG 共有 5,862 個前景像素，人工使用 502 個，排除 5,360 個。將排除的內容視為漏覆會誤導生成器包入不屬於此附件的內容。padding-03 階段生成 462 點，不能視為人工網格過疏；這是驗收範圍不吻合。

使用者已同意改按人工實際使用區域檢查。`artist-region-padding-5-v4` 以原始前景和人工外框的交集作有效前景，獨立重算漏覆 ≤2%；透明留白預算也以有效前景為分母。原始 PNG 和其雜湊不變，額外揭露人工排除像素。生成外框若重新包入被排除的其他原圖前景，單獨拒絕，不拿留白額度抵銷。這個區域來自人工參考，不是 AI 自行理解；生成器吃選定區域的 alpha，不直接複製人工頂點。普通 CLI 尚不自動完成私人參考區域選取。

### 工具順序

1. 用 `tools/spine-reference-export.json`，透過相容的 Spine CLI 將原檔唯讀匯出至 repo 外的新資料夾。
2. 外部 config 指定三份 source、export、images、freshExport、runs 與 tutorialEvidence。`tools/reference-corpus-check.mjs` 產生完整 report；拒絕覆寫既有資料夾。
3. `tools/render-reference-review.mjs` 重新核對來源雜湊，產生自包含 HTML 與審核 bundle。截圖是此真實數據頁，不冒充 Spine 編輯器操作畫面。
4. `tools/jev-gate-review.mjs` 先執行本機硬門檻；失敗就停止且不呼叫 Jev。通過後仍須有效 SDK／憑證與獨立審核，不能自行宣告 APPROVED。
