# AutoSpine plugin

Rig and animate Spine 4.0 characters and props from an images-only Spine file. Give Claude or Codex the Spine file and a one-line brief ("make the idle a 2-second breath, hand resting on the forehead"); it builds bones, meshes, weights, constraints and motion, renders a review video and writes handover notes. With the artist's version it also compares the two.

It delivers to Spine 3.8, 4.0, 4.1 or 4.2. For a game runtime (`--target=cocos`, `unity` or `unity-4.1`) it delivers with that runtime's editor version, adds an `Actor` bone under the root and checks the file against Spine game-delivery conventions: editor version, names, root and `Actor`, blend modes and `_Add`, points, clipping, weights, localised text and numbers, bone, triangle and draw-call limits, first keys, loop seams and win/loading animation names. `check-delivery` (MCP `autospine_check_delivery`) checks an artist's own `.spine` or JSON the same way, and with `--export` its `.skel`, `.atlas` and pages. The rules are in `skills/autospine/references/delivery-conventions.md`.

## Use it

Install the plugin. In Claude Code:

```text
/plugin install autospine --marketplace Wayne188-yiching/AutoSpine
```

For Cowork and Codex, see `docs/INSTALL.html` in the repository. Then ask in Claude Code, Cowork or Codex:

```text
用 autospine 把 D:\素材\角色\角色.spine 的 idle 做成 2 秒呼吸，輸出到 D:\輸出\角色
```

You need Node.js 22.12 or later. Exporting `.spine` projects and importing results needs Spine 4.0.64 (or the version you deliver to; the Spine launcher fetches it the first time); the review video needs ffmpeg.

## Contents

- `skills/autospine/` — the skill: instructions, references, the bundled engine (`scripts/`) and a runnable example character (`assets/example/`).
- `.mcp.json` (Claude) and `.codex-mcp.json` (Codex) — the local AutoSpine MCP server, workspace `~/AutoSpine`.
- `agents/` — Claude Code subagents with fixed models for the long-output steps: intake (haiku), reference scout (haiku), build and compare (sonnet, cannot edit plans), stage reviewer (opus) and an opt-in OpenAI Codex reviewer (ADR-055).
- `skills/autospine/delegate/codex-review.mjs` — runs one read-only, unsaved Codex review for that reviewer (`AUTOSPINE_CODEX`, `AUTOSPINE_CODEX_MODEL`, `AUTOSPINE_CODEX_EFFORT`).

`scripts/`, `references/` and `assets/` are generated by `tools/build-plugin.mjs` from the repository; edit the sources and rebuild. `agents/` and `delegate/` are written by hand.

## Data

Everything runs on the machine that runs the session. The plugin sends nothing anywhere itself. The Codex reviewer runs only when the requester asks for it or enables it; it then hands the review brief and the files it names to the local Codex CLI, which sends them to OpenAI under the requester's own Codex account.
