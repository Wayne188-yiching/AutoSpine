# AutoSpine plugin

Rig and animate Spine 4.0 characters and props from an images-only Spine file. Give Claude or Codex the Spine file and a one-line brief ("make the idle a 2-second breath, hand resting on the forehead"); it builds bones, meshes, weights, constraints and motion, renders a review video and writes handover notes. With the artist's version it also compares the two.

## Use it

Install the plugin. In Claude Code:

```text
/plugin install autospine --marketplace Wayne188-yiching/AutoSpine
```

For Cowork and Codex, see `docs/INSTALL.html` in the repository. Then ask in Claude Code, Cowork or Codex:

```text
用 autospine 把 D:\素材\角色\角色.spine 的 idle 做成 2 秒呼吸，輸出到 D:\輸出\角色
```

You need Node.js 22.12 or later. Exporting `.spine` projects and importing results needs Spine 4.0.64; the review video needs ffmpeg.

## Contents

- `skills/autospine/` — the skill: instructions, references, the bundled engine (`scripts/`) and a runnable example character (`assets/example/`).
- `.mcp.json` (Claude) and `.codex-mcp.json` (Codex) — the local AutoSpine MCP server, workspace `~/AutoSpine`.

`scripts/`, `references/` and `assets/` are generated by `tools/build-plugin.mjs` from the repository; edit the sources and rebuild.

## Data

Everything runs on the machine that runs the session. The plugin sends nothing anywhere itself.
