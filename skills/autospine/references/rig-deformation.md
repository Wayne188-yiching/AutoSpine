# 骨架、佈線與變形判斷

來源：本機課程 76 部完整離線 ASR 文字已研讀，另抽查重點畫面；詳見[研讀紀錄](../../../docs/SPINE_TUTORIAL_ENGINEERING_NOTES.md)。ASR 有誤聽，不把課程中的固定骨數、百分比、幀數或歷史引擎限制當通用規格。這些是操作規則，不是已完成的自動推定能力。

## 從素材制定控制方案

1. 確認 Editor／Runtime 版本、動作名稱、角色組裝座標、固定接觸處、活動範圍、表情終態和效能預算。區分動畫名稱與 event 名稱。
2. 按圖片、圖層名稱、角色相對位置、連接關係和預期動作分類。分別記錄用途、關節、控制方式的信心；課名或檔名不能代替圖片檢查。
3. 區分 root anchor、body motion、變形骨、IK target、方向控制、特效錨點。骨起點服務旋轉／縮放樞紐，不必位於圖片中心、前景或父骨末端。[官方工具說明](https://esotericsoftware.com/spine-tools)
4. 一張圖可含多鏈、多材質；多張圖可共用剛性控制。寬髮片、分叉、兩端懸掛帶子、貼地拖曳髮尾保留不同方案。控制骨存在不表示它必須影響每張 Mesh。
5. 先辨認缺圖與 painted overlap。超出素材可表達範圍時記錄素材缺口；權重與增加頂點不能創造像素。

## 佈線

- 無需形變的附件先選 Region 或剛性 Mesh。Alpha 輪廓是覆蓋基線；內部線按關節、固定端、材質界面與透視特徵配置。
- 肢體保留剛性段並在局部關節過渡，髮布按曲率與橫截面分區；不要把盔甲、手指和柔軟衣料都套相同拓樸。
- 使用達到活動範圍的最少有效頂點，檢查三角形有效性、覆蓋和翻折。明確邊用於必要的三角化限制，不需重描每條自動邊。
- 核對 UV、setup 頂點與圖片尺寸。Deformed off 編輯 UV，與同步修改頂點不同。Reset／Trace／Generate 可清掉权重與 deform，改既有 Rig 前另存並保留映射。[官方 Mesh 說明](https://esotericsoftware.com/spine-meshes)
- 名稱先去除已確認的路徑前綴與效果後綴，再配合相對位置分類。左右兩側的部件編號不一定同義；以組裝位置核對上／下肢段和手指順序。換圖比對完整附件身份，不以末尾 `_1` 等片段選擇表情。
- 有意保留透明眼／嘴孔的臉片可用 `generateSurfaceMesh` 的 UV 表面網格；原 PNG alpha 保留，成本是透明區的填色負擔。長條輪廓在關節附近產生極瘦三角形時，可試表面或 strip 配置；判準是彎曲後是否翻折，而非輪廓點數。
- `generateMesh` 的 `featurePoints` 接受有限且位於圖片內的特徵候選，由既有三角化引擎插入。清楚區分候選點與必須恢復的邊；前者不保證特定連線。

## 權重與修正

1. 先建立附件允許的變形骨、固定／剛性區與多鏈分區，再求權重。距離只是初值，不能讓接近的袖子、手、武器共享所有影響。
2. 檢查有限數、每頂點覆蓋、正規化、影響數和 setup pose；平滑不可跨應隔離的界面。影響裁減後重新測試動作。
3. 用獨立掃動動畫逐骨測預期範圍，再測全角色。觀察關節體積、髮根固定、飾物長寬、連接縫與不應被带動的區域。Animate Mode 中調權重避免誤改 setup。[官方權重說明](https://esotericsoftware.com/spine-weights)
4. 局部控制單獨合理仍需檢查組合後的總反應。多個控制不能各自給足權重後假定疊加仍合理。
5. 依原因修正：缺像素→素材；錯 influence→權重；缺少必要分區→拓樸；樞紐或父級錯誤→Rig；超出 brief→動態。不要以加骨、加點或全面平滑取代診斷。
6. 有重疊切圖的上下肢段可各自綁相應段，避免兩張圖都跨整條彎折鏈而塌陷。檢查裁切前的幾何，並為隱藏換圖附件建立獨立 setup 基準；裁切後頂點數不同不可直接宣稱翻面檢查通過。

現有 V1 權重最多 4 influences，距離求解排除零長度骨；這是 AutoSpine 求解器限制，Spine 的點骨仍可参与權重。教學中的 6 influences、多鏈或原生拓樸自動權重須另驗支援，不能直接宣稱工具已具備。

## 表情

- 按動作數、重用需求與活動範圍選 attachment、weighted bones、deform 的組合。少量表情與大量可組合表情的成本不同，輸出通道支援先確認。
- 保護畫師核准終態。眨眼分閉合、停留、睜開；眼皮弧線、眼白覆蓋、臉外緣與上下眼皮分工需檢查，數值 blink 不是完整眨眼。
- 換圖先核對畫布、錨點和 Mesh／權重相容；大動作或眨眼可讓轉接較自然，不能掩蓋錯位。轉面表情須與臉同步。
- 眼球跟隨與視線控制分層，眉毛牽連皮膚、嘴唇牽連下巴、額頭牽連帽子依實際素材設區域。不要把所有五官綁成同一個全臉控制。
- deform 可表達二維位移；課程說「只能一個方向」指它示範的控制工作流，並非格式禁令。新增或重綁後清查複製留下的舊 influence。
